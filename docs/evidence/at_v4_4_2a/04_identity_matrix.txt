  - Identity does NOT exist (files/at-cli-identity/ is EMPTY).
  - Identity profile: "at-cli-identity" (configured via ATAndroidConfig(identityProfile="at-cli-identity")).
  - This is EXPECTED_FIRST_USE_STATE, not a regression.
  - The ConsumerHost is a SEPARATE APK with its OWN UID and its OWN identity.
  - It CANNOT reuse the Product's identity (different UID, different filesDir).
  - Pairing entrypoint: AtCliConsumerTest.b3_pair() / firstUsePairing()
    via AtCliConsumerHost.composition().adbControl.pairDiscovered(code).
    Requires: (1) system pairing dialog open (user action), (2) 6-digit code
    staged via -e code instrumentation argument.
  - PAIRING_ENTRYPOINT_AVAILABLE = YES
  - PAIRING_REQUIRES_USER_6_DIGIT_CODE = YES
  - PAIRING_REQUIRES_SOURCE_CHANGE = NO
  - FIRST_USE_PATH: NO_IDENTITY -> discoverPairing (mDNS) -> user 6-digit code
    -> AdbConsumerBootstrap.pair -> AdbEngine.pair -> persistent identity
    -> AdbRuntime.ensureReady -> READY
  - Classification: FIRST_USE_BOOTSTRAP_REQUIRED (not a regression).
  - READY_FOR_DEVICE_TEST = NO (until first-use pairing is completed by user).
